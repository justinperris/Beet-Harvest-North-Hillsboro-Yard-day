Each Send reads that roster's file straight from GitHub, adds or updates the person by name (matching an existing row, or filling the first blank one), bumps its "last updated" stamp, and pushes it back. Name auto-complete is this sheet's own memory (starts empty, holds up to 80 names, keeps them after a send). Suggestions appear once you've typed 3 letters. Names are matched case-insensitively (“dave stewart” = “Dave Stewart”). If the same name is on more than one row, that row is flagged and Send asks you to confirm.
